# Changelog

## uisapi 0.1.2

- Package links now point to the econdataverse GitHub organization.
- [`uis_get_indicators()`](https://econdataverse.github.io/r-uisapi/reference/uis_get_indicators.md)
  now parses `last_data_update` dates in both formats returned by the
  API.

## uisapi 0.1.0

CRAN release: 2025-03-06

- Initial release with
  [`uis_get()`](https://econdataverse.github.io/r-uisapi/reference/uis_get.md),
  [`uis_get_entities()`](https://econdataverse.github.io/r-uisapi/reference/uis_get_entities.md),
  [`uis_get_indicators()`](https://econdataverse.github.io/r-uisapi/reference/uis_get_indicators.md),
  [`uis_get_versions()`](https://econdataverse.github.io/r-uisapi/reference/uis_get_versions.md),
  and
  [`uis_bulk_files()`](https://econdataverse.github.io/r-uisapi/reference/uis_bulk_files.md).
